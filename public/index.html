Steal-the-VFY Match Reconstructor

Replay a match's turn sequence and prove each move was legal. Paste a match (matchId + ordered turns) and get the reconstructed state after every turn plus a per-turn LEGAL / ILLEGAL verdict against the published Steal-the-VFY rules.

Honest scope — read this first. This tool does state reconstruction + legality only. It checks the turn sequence you paste against the published protocol (SPEC.md §4) and against a board model that is explicitly labeled as an assumption below — the platform has published no board, cells, ownership, or adjacency, so no board rule here is protocol. It uses no live data, generates or verifies no proofs, makes no platform calls, and stores nothing: everything runs in memory and is discarded.

1 · Paste a match

Format: { "matchId": "…", "turns": [ { "matchId", "turn", "actor"?, "action": { "type", "amount"?, "target"? }, "idempotencyKey"? } ] }. actor defaults to "self"; use "opponent" for the other side's turns. A turn may also carry state: { "self": n, "opponent": n } — the balances the platform's envelope reported before the turn — which the tool cross-checks against its own reconstruction.


2 · The assumed board model

The platform publishes no board. To check ownership and adjacency at all, this tool assumes a 3×3 grid (cells A1–C3, rows A–C, columns 1–3) with orthogonal adjacency only (diagonals do not count), and this starting ownership:

     1        2        3
A  self     self     opponent
B  self     opponent neutral
C  neutral  neutral  opponent

Under this model a STEAL target must be opponent-owned and orthogonally adjacent to a cell the actor owns; a FORTIFY target must be owned by the actor and marks the cell fortified; a fortified cell cannot be stolen; a STEAL moves its amount from the victim's balance to the actor's. Every one of these is an assumption — change the board and the verdicts change with it. The published rules (action set, amount omission, turn order, idempotency, 20-turn cap, 100 VFY start) hold regardless of the board.
